# Porftolio

Portfolio personal desarrollado con React y Vite.

## Desarrollo

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```

La página principal es la aplicación React. El formulario de contacto permanece
en `form.html`, y las certificaciones se cargan desde `data/cursos.json`.

El formulario envía los mensajes mediante FormSubmit. La primera vez, el
destinatario debe confirmar la activación desde el correo que envía el servicio.
